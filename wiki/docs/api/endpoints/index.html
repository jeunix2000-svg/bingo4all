API エンドポイント一覧

投稿 (posts / search)​

メソッドパス概要
GET/posts投稿一覧・検索（q, category, postType, sort, ページング）
POST/posts投稿作成
GET/posts/{id}投稿詳細
PUT/posts/{id}投稿編集
DELETE/posts/{id}論理削除
POST/posts/{id}/transition状態遷移

評価 (evaluation)​

メソッドパス概要
POST/posts/{id}/votesいいね/低評価（direction: 1 / -1）
POST/posts/{id}/ratings多軸価値評価（実用性・正確性・新規性）
POST/posts/{id}/verify検証済みマーク（レビュアー以上）

貢献 (contributions)​

メソッドパス概要
GET/posts/{id}/contributions回答・補足一覧
POST/posts/{id}/contributions回答/補足投稿
POST/contributions/{id}/acceptベストアンサー/補足採択

統計 (stats)​

メソッドパス概要
GET/stats/me個人ダッシュボード
GET/stats/org全社統計
GET/stats/knowledge-gapナレッジ・ギャップ

運用 (moderation)​

メソッドパス概要
GET/moderation/reports通報キュー
POST/moderation/reports投稿通報

AI (ai)​

メソッドパス概要
POST/ai/assist概要/分類/タグ/重複/推敲
POST/ai/reviewAI Reviewer（信頼度・参考資料）

主要スキーマ​

PostCreate（必須フィールド）​

  • title, categoryCode, postType, summary, body, confidentiality
  • 任意: tags[], attachmentIds[]

ValueRating​

  • usefulness, accuracy, novelty — 各 1〜5

UserStats​

  • postCount, upvotesReceived, totalPoints, level, acceptedContribs, badges[]

完全なスキーマ定義は OpenAPI YAML を参照。
