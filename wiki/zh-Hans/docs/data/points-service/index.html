积分微服务

承担 YFC 内部 Wiki 评分·排行榜·防作弊 的独立微服务（ADR-002）。

📄 DDL: 下载 yfc_points_service.sql

设计方针（4 原则）​

  1. point_events = 仅追加台账 (append-only ledger) — 唯一真实来源。符合 ISMS/审计日志。
  2. 余额/评价 = 派生聚合 — award_points() 在同一事务内同步更新。
  3. 防作弊 (anti-gaming) — 自投禁止 / 日上限 / 评价者评价加权 / 互赞检测 / 低质量惩罚。
  4. 质 > 量 — 基础分低，主要得分来自他人评价·采纳·引用。规则数据化 (point_rule)。

Schema 构成​

分类表说明
A. 主数据user_type, category, post_type, level_def, badge_def, point_rule参考·评分规则
B. 镜像app_user, post, contributionWiki 侧最小镜像
C. 评价vote, value_rating投票·多轴评价
D. 台账point_event仅追加·真实来源
E. 聚合user_point_balance, user_domain_reputation, user_badge, gaming_alert派生数据

核心函数 award_points()​

评分核心。在同一事务内：

  1. 规则获取（禁用时 0 分）
  2. 受益者决定（SELF / TARGET_AUTHOR）
  3. 防作弊①：禁止自我操作
  4. 防作弊②：日上限
  5. 评价者评价加权（0.5〜1.5）
  6. 台账记账（UNIQUE 防重复）
  7. 余额 + 等级更新
  8. 领域评价更新（≥800 获验证者资格）
