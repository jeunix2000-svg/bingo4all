ADR-006：工具连接以 MCP 标准化

项目内容
背景不希望 Agent 连接外部数据/工具的方式因项目而异。
决定设立 MCP Gateway，作为工具连接的标准接口。
状态采纳 (Accepted)
影响连接方式统一，复用·审计·权限控制容易。
替代方案个别 API 实现（重复·维护负担）
