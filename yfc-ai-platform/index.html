YFC AI Knowledge Platform

全社 AI 内製の共通基盤。社内 Wiki を Module 1 として実装し、 積分サービス・RAG・MCP Gateway へ段階的に拡張する開発リポジトリです。

パッケージ構成

platform-core

IF 定義

Embedding / VectorStore / RagEngine / PromptLibrary / McpGateway

wiki-module

実装済 · HTTP 14件

Posts CRUD・状態遷移・投票/評価・権限制御（:8080）

point-service

実装済 · テスト済

積分マイクロサービス・台帳冪等・信誉加重（:8081）

db / openapi

PG 検証済

Flyway V1–V3（pgvector）· OpenAPI 3.0 仕様

公网 API（Render）

  • Wiki API — 在 portal-config.js 配置 wikiApiUrl
  • 门户知识库页面 — wiki-app.html
  • 数据库需执行 Flyway V4 演示用户迁移
  • Render 环境变量建议设置 PORTAL_ORIGIN 为门户公网域名

ローカル起動（開発者向け）

  • npm install → docker compose up -d db
  • npm run db:migrate → Flyway でスキーマ適用
  • npm run start:wiki — Wiki API :8080
  • npm run start:points — 積分 API :8081
  • npm test — 全ワークスペーステスト
