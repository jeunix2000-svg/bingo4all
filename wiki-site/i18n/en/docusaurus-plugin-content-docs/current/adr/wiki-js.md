# ADR-001: Adopt OSS (Wiki.js) as Wiki Foundation

| Item | Description |
| --- | --- |
| **Context** | A foundation that satisfies posts, Markdown, search, permissions, and OIDC is required. Full in-house development would be excessive effort. |
| **Decision** | Adopt the proven OSS Wiki.js and concentrate in-house effort on unique value (points, AI). |
| **Status** | Accepted |
| **Consequences** | Roughly 70% effort reduction. OSS constraints are absorbed via plugins/integrations. OSS assets remain on exit. |
| **Alternatives** | Full in-house build (over-investment) / SaaS Confluence (unsuitable due to points requirements and data sovereignty) |
