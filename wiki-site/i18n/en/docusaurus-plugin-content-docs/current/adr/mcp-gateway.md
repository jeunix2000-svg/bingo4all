# ADR-006: Standardize Tool Connectivity with MCP

| Item | Description |
| --- | --- |
| **Context** | We do not want agents to connect to external data/tools in inconsistent ways per project. |
| **Decision** | Establish MCP Gateway as the standard interface for tool connectivity. |
| **Status** | Accepted |
| **Consequences** | Unified connectivity enables reuse, audit, and access control. |
| **Alternatives** | Individual API implementations (duplication, maintenance burden) |
