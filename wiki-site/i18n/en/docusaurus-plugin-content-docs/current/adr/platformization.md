# ADR-005: Platformization (Wiki as First Module)

| Item | Description |
| --- | --- |
| **Context** | Follow-on AI projects (sales daily report / hiring evaluation / COBOL migration) would fragment the foundation if optimized individually. |
| **Decision** | Commonize the knowledge foundation (Embedding/Vector/RAG/Agent/MCP) and make Wiki the first consumer. |
| **Status** | Accepted |
| **Consequences** | Follow-on projects plug into the foundation. AI investment compounds company-wide. Standard template adoption. |
| **Alternatives** | Per-app individual builds (duplicate investment, difficult governance) |

See [Evolution Roadmap](../roadmap/phases).
