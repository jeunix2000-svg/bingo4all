# Evolution Roadmap

Establish foundation and operations with Wiki, then plug follow-on AI projects into the same base to evolve into **YFC AI Platform**.

| Phase | Theme | Content | Effort |
| --- | --- | --- | --- |
| **Phase 0** | Wiki PoC | SSO + posts + search + upvotes + basic points | ~3.0 person-months |
| **Phase 1** | Wiki production | Ratings/acceptance/search/dashboard/AI assist | ~3.0 person-months |
| **Phase 2** | Platformization | Embedding / Vector (pgvector) / RAG / semantic search | ~4.0 person-months |
| **Phase 3** | Agentization | Agent Memory / Workflow / Prompt Library | ~4.0 person-months |
| **Phase 4** | Multi-app rollout | Sales daily report AI / hiring evaluation AI / COBOL migration AI as plugins, MCP integration | Per project |

## Phase 0 — Wiki PoC

- Entra ID SSO integration
- Basic posts · Markdown editing
- Full-text search
- Upvotes + basic `POST_CREATE` scoring

## Phase 1 — Wiki Production

- Multi-axis ratings · best answer acceptance
- Personal/org dashboards
- AI assist (summary/tags/dedup)
- Knowledge gap visualization

## Phase 2 — Platformization

- Embedding + pgvector introduction
- Semantic search (RAG foundation)
- Knowledge Graph kickoff

## Phase 3 — Agentization

- Agent Memory
- Workflow Engine
- Prompt Library full operation

## Phase 4 — Multi-App Rollout

- MCP Gateway integration
- Sales daily report AI / hiring evaluation AI / COBOL migration AI

Each project plugs into Platform Core and shares the knowledge foundation.
