# 时序设计

展示主要流程的时序，作为实现·调试的基准。

## 4.1 文章发布流程

```
发布者          Wiki API        AI Gateway      Points Service    PostgreSQL
  │                │                │                 │                │
  │ POST /posts    │                │                 │                │
  │───────────────>│ 保存           │                 │                │
  │                │──────────────────────────────────────────────────>│
  │ POST /ai/assist│                │                 │                │
  │───────────────>│ 辅助请求       │                 │                │
  │                │───────────────>│                 │                │
  │                │<───────────────│ summary,tags    │                │
  │ POST transition│                │                 │                │
  │  (submit)      │                │                 │                │
  │───────────────>│ REVIEW 状态    │                 │                │
  │                │                │                 │                │
  │ POST transition│                │                 │                │
  │  (publish)     │                │                 │                │
  │───────────────>│ PUBLISHED      │                 │                │
  │                │ Webhook        │                 │                │
  │                │───────────────────────────────>│ POST_CREATE      │
  │                │                │                 │ award_points     │
  │                │                │                 │───────────────>│
  │                │<───────────────────────────────│ 200 OK           │
```
