# 非功能需求（性能·容量）

以 PoC〜初期生产（用户约 1,000·投稿 10 万件）为前提的量化指标。

## TPS / 响应时间（P95）

| 操作 | 目标 TPS | P95 响应 | 备注 |
| --- | --- | --- | --- |
| 登录 (SSO) | 200 TPS | ≤ 800ms | 含 Entra 委托 |
| 搜索 (列表/全文) | 100 TPS | ≤ 1,000ms | 语义搜索迁移后仍维持 |
| 投稿 (创建/更新) | 50 TPS | ≤ 1,500ms | AI 辅助可异步 |
| 评价/投票 | 100 TPS | ≤ 600ms | 含自投拒绝 |
| AI 辅助/RAG | 20 并发 | ≤ 6s (生成) | LLM 速率控制 |

## 容量·扩展方针

### 水平扩展

Wiki / Point / AI Gateway **无状态化**，通过容器复制扩展。

### 数据库

- 通过读副本分离搜索/统计负载
- pgvector 以 IVFFlat / HNSW 索引优化近邻探索

### AI 并发执行

- 并发执行上限 20，队列控制
- 突发时异步化（概要/标签可后续反映）

### 计量

各操作设定 SLO（TPS/P95），在 CI 内负载测试进行回归检测（[测试策略](../devops/test-strategy)）。
