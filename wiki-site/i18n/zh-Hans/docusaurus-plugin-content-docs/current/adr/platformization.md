# ADR-005：平台化（Wiki 作为第 1 模块）

| 项目 | 内容 |
| --- | --- |
| **背景** | 后续 AI 项目（营业日报/招聘评估/COBOL 迁移）若各自优化会导致基盘林立。 |
| **决定** | 共通化知识基盘（Embedding/Vector/RAG/Agent/MCP），Wiki 作为首个使用者。 |
| **状态** | 采纳 (Accepted) |
| **影响** | 后续项目向基盘插件化。全公司 AI 投资复利化。标准模板化。 |
| **替代方案** | 各应用单独构建（重复投资·统制困难） |

参见 [演进路线图](../roadmap/phases)。
