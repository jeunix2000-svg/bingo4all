# ADR-006：工具连接以 MCP 标准化

| 项目 | 内容 |
| --- | --- |
| **背景** | 不希望 Agent 连接外部数据/工具的方式因项目而异。 |
| **决定** | 设立 MCP Gateway，作为工具连接的标准接口。 |
| **状态** | 采纳 (Accepted) |
| **影响** | 连接方式统一，复用·审计·权限控制容易。 |
| **替代方案** | 个别 API 实现（重复·维护负担） |

引入阶段: Phase 3-4（[路线图](../roadmap/phases)）
