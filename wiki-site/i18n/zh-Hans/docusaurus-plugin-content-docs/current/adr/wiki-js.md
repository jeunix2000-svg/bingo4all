# ADR-001：Wiki 基盘采用 OSS（Wiki.js）

| 项目 | 内容 |
| --- | --- |
| **背景** | 需要满足投稿·Markdown·搜索·权限·OIDC 的底座。完全自研工数过大。 |
| **决定** | 采用有实绩的 OSS Wiki.js，将内制集中于独有价值（积分·AI）。 |
| **状态** | 采纳 (Accepted) |
| **影响** | 工数约削减 7 成。OSS 约束通过插件/集成吸收。撤退时 OSS 资产仍可保留。 |
| **替代方案** | 完全自研（过度投资）／SaaS Confluence（积分需求/数据主权不适用） |
