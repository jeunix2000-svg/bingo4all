# ADR-005：プラットフォーム化（Wiki を第 1 モジュール化）

| 項目 | 内容 |
| --- | --- |
| **背景** | 後続 AI 案件（営業日報/採用評価/COBOL 移行）が個別最適化すると基盤が乱立する。 |
| **決定** | 知識基盤（Embedding/Vector/RAG/Agent/MCP）を共通化し、Wiki を最初の利用者とする。 |
| **状態** | 採用 (Accepted) |
| **影響** | 後続案件は基盤にプラグイン。全社で AI 投資が複利化。標準テンプレート化。 |
| **代替案** | アプリ毎の個別構築（重複投資・統制困難） |
