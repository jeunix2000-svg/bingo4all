# アーキテクチャ決定記録（ADR）

「どう設計するか」に加え **「なぜそう決めたか」** を記録し、新規参画者と後続案件が前提を理解できるようにする。

各 ADR は **背景 / 決定 / 状態 / 影響 / 代替案** で記述する。

| ADR | タイトル | 状態 |
| --- | --- | --- |
| [ADR-001](./wiki-js) | Wiki 基盤に OSS（Wiki.js）を採用 | 採用 |
| [ADR-002](./points-microservice) | 積分サービスを独立マイクロサービス化 | 採用 |
| [ADR-003](./postgresql-pgvector) | PostgreSQL + pgvector を採用 | 採用 |
| [ADR-004](./claude-api) | LLM に Claude API を採用 | 採用 |
| [ADR-005](./platformization) | プラットフォーム化（Wiki を第 1 モジュール化） | 採用 |
| [ADR-006](./mcp-gateway) | ツール接続を MCP で標準化 | 採用 |
