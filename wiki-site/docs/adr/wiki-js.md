# ADR-001：Wiki 基盤に OSS（Wiki.js）を採用

| 項目 | 内容 |
| --- | --- |
| **背景** | 投稿・Markdown・検索・権限・OIDC を満たす土台が必要。フル自研は工数過大。 |
| **決定** | 実績ある OSS Wiki.js を採用し、独自価値（積分・AI）に内製を集中する。 |
| **状態** | 採用 (Accepted) |
| **影響** | 工数約 7 割削減。OSS の制約はプラグイン/連携で吸収。撤退時も OSS 資産が残る。 |
| **代替案** | フル自研（過剰投資）／SaaS Confluence（積分要件/データ主権で不適） |
