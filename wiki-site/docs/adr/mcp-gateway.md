# ADR-006：ツール接続を MCP で標準化

| 項目 | 内容 |
| --- | --- |
| **背景** | Agent が外部データ/ツールに接続する方式を案件毎にばらつかせたくない。 |
| **決定** | MCP Gateway を設け、ツール接続の標準インターフェースとする。 |
| **状態** | 採用 (Accepted) |
| **影響** | 接続方式が統一され、再利用・監査・権限制御が容易。 |
| **代替案** | 個別 API 実装（重複・保守負荷） |

導入段階: Phase 3-4（[ロードマップ](../roadmap/phases)）
