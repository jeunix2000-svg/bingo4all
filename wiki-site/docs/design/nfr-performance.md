# 非機能要件（性能・容量）

PoC〜初期本番（ユーザー約 1,000・投稿 10 万件）を前提とした定量化指標。

## TPS / 応答時間（P95）

| 操作 | 目標 TPS | P95 応答 | 備考 |
| --- | --- | --- | --- |
| ログイン (SSO) | 200 TPS | ≤ 800ms | Entra 委譲含む |
| 検索 (一覧/全文) | 100 TPS | ≤ 1,000ms | 意味検索移行後も維持 |
| 投稿 (作成/更新) | 50 TPS | ≤ 1,500ms | AI 支援は非同期可 |
| 評価/投票 | 100 TPS | ≤ 600ms | 自票拒否含む |
| AI 支援/RAG | 20 同時 | ≤ 6s (生成) | LLM レート制御 |

## 容量・スケール方針

### 水平拡張

Wiki / Point / AI Gateway は **ステートレス化** しコンテナ複製で拡張。

### データベース

- 読み取りレプリカで検索/統計負荷を分離
- pgvector は IVFFlat / HNSW インデックスで近傍探索を最適化

### AI 同時実行

- 同時実行 20 を上限にキュー制御
- バースト時は非同期化（概要/タグは後追い反映可）

### 計測

各操作に SLO（TPS/P95）を設定し、CI 内の負荷試験で回帰検知（[テスト戦略](../devops/test-strategy)）。
